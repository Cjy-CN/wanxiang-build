# 觉醒、过牌与升阶：比较机会成本后再决定

适用于每个会改变觉醒、升阶或搜牌时点的节点。预算闭合只证明付得起；本节比较同一资源的替代用途。**不得先写“优先觉醒”，再用完成体产出为它补理由。** 此流程由 agent 建立候选、解释事件和作判断；脚本只复核账本、概率式及差分，不生成整套策略。

## 1. 固定决策状态与比较目标

记录本回合操作前的棋手等级、商店本回合生效阶数、现金、上场及手牌、各英雄真实等级和已打出张数、商店四槽及锁定状态、免费刷新、天赋、棋手计数、对手占池、血量与下一战威胁。已知牌和未来随机来牌分开。

先说明优化目标：避免下一战出局是约束；之后比较在相同观察期限内能兑现的战力与队伍成长。若只有等级生产资料，就称“该成长模型下最优”，不能把它升级为胜率最优。主C、前排的等级分布和技能节点必须参与判断，不能只最大化所有挂件的等级总和。

按 [资源分配与战斗评估](combat-evaluation.md) 先找本节点瓶颈：主C缺伤害/接敌、保护不足、单点失能风险，还是未来生产不足。把补主C、补保护/副C与扩增长引擎放入相关竞争动作；不能用“每轮多若干全队等级”直接给觉醒/升阶定优先级。

共同观察期限至少覆盖两种顺序各自完成关键投资后的第一个有效周期，并检查较短的生存窗口。不能选“觉醒刚生效、升阶组件还未工作”的截止点证明觉醒好，也不能无限延长游戏来抹平早期淘汰风险。

## 2. 列出可执行的竞争动作

至少比较与本节点相关的三类：

- **先完成觉醒**：本轮买剩余同名牌或已知合法进度牌，之后何时升阶、何时有钱实际获取高阶组件。
- **先升阶**：本轮升阶或存到明确的下一回合升阶，何时刷新新卡池、可留多少钱买牌；之后再完成旧组件觉醒。
- **先获取/使用有效牌**：买新的放大器、成组转型或必要战力；将购买后的补槽、登场、合成、棋手计数等一起计算。仅为过牌的买卖也要与直接刷新竞争。

“继续搜到觉醒”不是一个有界动作。明确本轮目标集合、最多额外刷新几次、停止余额、买到/没买到后分别何时升阶。每看见一次新的商店结果就更新状态，不能假设先看完整条随机来牌再回头选第一步。

已有首张、尚差三张的普通商店觉醒，剩余直接支出是9能量；差两张是6，差一张是3。已买的牌是共同前史，不重复收取9，也不能因已经投入就强行追完。搜索费、觉醒失败时仍有的合成收益分别记录；普通效果锦囊及其生成的普通效果牌不消耗能量；明确收费的棋手秘技等按自身费用执行，「如梦似幻」使用费为6能量。获取与使用分开记账，具体效果的战斗价值另行建模。低阶与高阶英雄同为3能量一张；低阶的差别是池与资格，**不是觉醒直接价格更便宜**。

合成进度（0、1、2）还应作为独立状态记录：第三次对已上阵同名英雄打牌会发放效果锦囊，不能只把这张牌当作觉醒或等级支出。第三次合成发生在升阶前还是升阶后，会分别按旧棋手等级或新棋手等级锁定锦囊品阶；打开时消耗1张锦囊，3个卡槽的品阶独立按规则§3.1.1抽取，随后三选一。本段普通锦囊及其生成的普通效果牌不消耗能量（不覆盖明确收费的棋手秘技），效果牌独立于公共卡池且无张数概念，因此不再因“池中剩余张数”扣减指定牌概率；但未确认具体卡文限制前，仍不能把随机结果折成固定战力。

## 3. 同时推进两条时间线

内部并列表至少记录：

| 净留存英雄等级及各自技能节点 | 旧过渡英雄退场携带的等级损失要扣掉；不能只比生成流水 |
| 关键击杀与失能顺序 | 属性/技能变化能否缩短击杀所需出手、延长主C可输出时间；关键减员后重算目标与保护，不能只比较开战面板 |

| 血量风险与转型损失 | 来得及回本才是收益；已知无法存活的动作先排除 |

用户2026-09-15已确认**新阶数卡池下回合刷新时生效**（规则§6.1.1）。令本回合商店生效阶数为回合开始时的棋手阶数：操作阶段升阶，不改变当轮手刷或购买补槽的卡池，R+1自动刷新才接入新品阶。已确认的免费刷新或付费刷新都不能提前生效。锁住一槽保留指定牌，也占用后续一次新槽机会。不要将新卡池延迟误扩展成人口/天赋全部延迟。

## 4. 为丢失的卡池机会定量

按用户确认的**≤生效阶数英雄联合卡池**建立商店分母，不自行加入“先按品阶概率抽阶数”的独立过程。先排除被禁和已占用的英雄实体牌，英雄数量按1至5阶的14/11/9/7/6原始池核对。效果牌不在公共英雄卡池内，没有张数和占池扣除；锦囊按独立抽阶规则生成选项，其他卡牌或棋手产生效果牌时仍按各自原文处理。

默认计算可采用明确标为假设的剩余实体牌等权模型：合格池共M张，某目标剩c张，则每次单槽`p=c/M`；品阶k剩`M_k`张时`p_k=M_k/M`。一次四槽若无放回，`P(至少一张目标)=1−C(M−c,4)/C(M,4)`，凑足d张用对应超几何尾概率。抽取或锁定后更新剩余池；未购买槽退回、已购买补槽与其他玩家占用按实际时点处理。跨多轮不能一律当成一次无放回抽样。

效果锦囊不使用英雄商店分母：对锦囊品阶`b`，3个卡槽分别独立抽取品阶`K_j`，使用规则§3.1.1中`p_b(K_j)`；在确定的品阶`K_j`内，各效果牌等概率出现。品阶独立不自动证明三个具体牌名独立或允许重复；涉及具体牌组合概率时注明抽样假设。三选一的价值按下节结合构筑评估，不能按品阶赋固定分，也不能把三个槽当成三张都获得。

令 `p(j,k)` 为给定路径第j个新槽见到品阶k的条件概率，固定曝光计划下`E[N_k]=Σ_j p(j,k)`。若槽数取决于来牌后购买/停搜，连同该计划的发生概率一起求期望。这是期望张数，不是至少见到一张的概率，也不是买得起的张数。只有独立、概率固定且忽略池变动的近似成立时，才用`1−(1−p)^m`；不将每轮四槽无放回模型与这个近似混为一谈。

高阶机会的价值来自**所有会改变最优动作的可用结果**，包括替代引擎与即时战力，不只当前想要的雅典娜/小乔。对“无目标、第一张到、够觉醒、别的有效高阶到”的合法结果分别推进；无概率时保留这些情景，不等权伪装成真实期望。

要计算的是不同顺序的**增量收益**：晚一轮上雅典娜，损失的是这一轮本可兑现的重放、承伤及其后续累计影响，不是再扣掉雅典娜整局的全部价值。若已在完整路径状态中体现晚到损失，就不能另外减一次“卡池机会费”。升级天赋也一样，已计入战力/现金后不再重复加分。

### 4.1 效果牌与构筑联动的评估路径

由运行时 agent 读取实际卡文并推演，不预制固定效果牌强度表。品阶只用于抽样概率和卡文资格；**不预设高阶牌或高阶锦囊价值更高**。三选一公式中的价值必须依赖当前局面，不能把品阶、平均等级或脱离构筑的单卡分直接作为效用。

1. **固定状态与对照。** 记录当前阵容及觉醒/等级、棋手、装备/天赋、手中效果牌与锦囊、合成进度、回合、血量和后续采购分支。沿用本节共同观察期限和同一评价目标；以没有新增这张效果牌、但其他资源仍可正常使用的路径为对照。已经看到的三张逐张比较；未打开的锦囊才对可能选项求期望。
2. **解析效果与事件。** 对每个有机会改变决策的选项，核对目标资格、直接收益和持续时间，按“获得 → 选择 → 留存/使用 → 直接效果 → 实际触发的英雄/棋手/装备/天赋监听 → 状态变化”展开。获得效果牌不等于已使用，推进觉醒不自动算一次同名英雄合成；返还、复制、重放、每回合上限和循环终止按原文判断。
3. **检查协同与冲突。** 同时查已有手牌的组合、核心觉醒门槛、升级/人口门槛、等级技能节点、装备/目标争用、收益封顶、过渡牌即将出售和临时效果到期。联动包含让生产者活到下一次触发的保护；不能只统计卡面直接加了多少级。移除关键接收者后重新看收益，判断价值来自牌本身还是当前构筑；未到组件只进入相应未来分支，不算已存在的联动。
4. **重新推进后续动作。** 比较选中后立即用、合理留存后用及必要时丢弃的路径，记录目标与使用回合。若这张牌省下同名牌支出、补完觉醒、创造转型入口或改变生存窗口，重新决定后续买牌/升阶/停搜；不能固定原来的运营表再机械加收益。免费使用仍会消耗这张牌和三选一的选择机会。连续开多个锦囊时，每次观察结果后更新状态，不把相同状态下的单包价值简单乘包数。
5. **比较增量并交付动作。** 在共同期限内比较留存英雄等级及关键分布、兑现的输出/承伤、资源余额和下一步成长。只有已定义可比效用时才合成单一数值，否则给逐项差分、情景边界与唯一临时首选，按第5节处理。内部保留“选项/目标与时点/完整触发链/后续动作变化/净收益及失败条件”；报告只呈现影响取舍的证据，不为所有无关效果牌逐一写长评。

可用记号：`ΔV(C | S,H)` 是在状态S选择牌C后，允许调整后续合法动作，到共同期限H相对对照路径的预期效用增量。效用目标与第5节一致，若仅评估成长须明确限定。锦囊的选择价值为 `J_b(S,H)=E[ max_{j=1,2,3} ΔV(C_j | S,H) ]`；留存/丢弃计入每个选项的后续动作。此式比较一张被选中牌的整条路径，不求三张收益之和，也不承诺已求出全局最优。若完整运营路径已包含锦囊带来的收益，不再额外加一次J。

锦囊内品阶k的合法候选有n_k种时，某一牌在单槽出现的边际概率为`p_b(k)/n_k`。候选集合按资料及明确获取限制核对，不凭当前阵营偏好先删掉“不想要”的效果牌再归一化，也不把只由特定棋手生成的子卡自动加入锦囊。降低详细评估范围可按相同作用分组、用有依据的收益上界排除劣势结果，但必须保留未展开结果的概率质量。

检查至少能解释以下反例：低阶进度牌刚好补完成长核心，可能优于高阶纯数值牌；同一效果牌在有/无使用监听器时价值不同；留到监听器到场后使用可能更赚但也可能错过保命时点。比较先觉醒和先升阶时，分别按各自产生锦囊时的状态与品阶评估J：高阶锦囊减少所需低阶牌的概率时，升阶不保证提升锦囊价值。锦囊获得后品阶已锁定，延后打开不会提高品阶；联动来自合理改变使用时机与后续动作。

### 4.2 经济、检索功能位的阶段价值与退出

经济/检索牌的价值随剩余目标、现金、卡池、可用回合和自身战斗能力变化，不把固定产出当作整局恒定收益。本地固定收入由R1—R3的6提高至R12起的15，同样+1能量占比下降，但这只说明相对收入变小：若这1点仍能让关键购买/升阶提前，价值可能很高；若未来已经无可兑现的支出，新增能量的边际价值才下降。检索也不是普通收入的等价物：定向获取、跨阶获取或稀缺目标的可达性按实际卡文评估，不能随基础收入同比打折。

对相关功能位，从入场时就规划“何时停止追加、何时退出、谁承接位置”，并在升阶、关键件到手、资源不再卡门槛或战斗压力改变时重判：

1. **找出仍未解决的资源缺口。** 写明保留它还能让哪笔必要动作提前，或增加在有效期限前完成哪组牌的机会；区分缺钱、缺目标牌、缺出手时间和缺人口位置。新增随机牌/免费刷新必须能被使用，不能把无效检索次数计成固定收益。
2. **只算当下起可兑现的功能收益。** 按实际触发条件、阶段与存活要求逐回合推进，到共同期限为止；替换后停止旧单位未来产出。回合开始已领取的收益与卖出回收另记，不能重领。过去赚过的资源已经体现在当前状态，不能为了证明继续保留而再加一次；初次买入/觉醒的决策则要比较从入场到退出的完整净收益。
3. **分开等级库存与当前贡献。** 功能位高等级可能仍提供承伤、控制或副输出，也可能不改善任何关键战斗事件；按战斗评估判断，不能把等级全归零或与主C等价。另记可定向成长/装备是否应停止投入、不可定向的群体成长如何继续分配。后者不是玩家可自由转走的资源；只有替换能合法改变分配时才计改道收益。
4. **从同一状态比较退出路径。** 至少比较相关的立即换实际可用战斗位、保留至明确下一触发/目标后换，以及有已证转移机制时转移再换。候选替代者按实际等级、装备和到场时点计算，未抽到的终局高阶牌不作为无条件替代。缺替代或当前高等级功能位仍是必要前排时，允许暂留并停止追其觉醒/定向强化。
5. **核对转移与重建。** 转移需要实际持有/可获得的合法牌及明确规则，逐项核对目标、永久/临时等级、移除方式、比例/上限、装备和触发时序。没有转移途径就按实际损失重算新队及其后续分配，不能默认等级继承。也不因“已养很高”永久保留：既有等级产生的当前战力是比较项，历史投入本身不是保留理由；没有转移手段不自动证明早期购买错误。
6. **确定退出条件与采购动作。** 比较“保留功能位的剩余资源兑现＋当前战斗作用”与“替换后的战斗/增长改善”，计入购牌、退出回收、装备与等级损失、等待和风险。同一损失若已反映在两条路径状态中，不再折成额外扣分。达到退出条件后给出R几停买同名、先买谁、何时转移/出售和替代未到的下一检查点；不能只写“后期换掉”。

需要定量时，在已定义同一效用与期限的条件下，可用 `ΔV_资源=V(S获得额外资源后的可执行后续路径)−V(S原可执行后续路径)`；价值由它改变的动作决定，不固定把1能量折成1等级或给功能牌设随回合递减系数。检索采用该动作实际选项和成型机会的增量，不能与普通现金重复计算。未来期末库存只按可信的剩余用途计价，无用牌不能按英雄售价虚构回收。

两个反例都要能解释：阵容已齐、能量充足、余下窗口短时，继续为产能牌觉醒可能无法回本；仍缺关键牌、额外检索有独特获取优势时，即使基础收入很高也可能值得保留。前期赚资源、后期换战斗位的路线应评整段运营，不因最终出售损失等级便一概否定；也不把过去累计收入用于掩盖当前占位损失。

## 5. 比较结果并形成唯一动作

优先尝试逐项支配：同一生存约束、观察期限和可比输入下，某动作留存成长/战力不差、关键节点不晚、资源或机会至少一项更好，且未隐藏另一项损失，才可直接淘汰竞争动作。

有来源的概率与可比效用时，比较 `Q(a)=Σ_ω P(ω|当前状态,a)×U(该路径至H的结果)`。效用U必须先定义并统一应用；不能事后调整成长/血量权重让原推荐获胜。完整路径已包括支出结果，不再从Q机械扣9分或9级。反事实对照使用同一外部随机条件/分布，允许因棋手等级不同出现不同牌；不能把另一条路线未来看见的牌提前泄露给本节点。

U应体现当局目标下可兑现的战斗结果与后续机会。只有等级证据时，等级差只能支持资源生产比较，不能直接决定正式阵容排名。缺少可信胜负效用时保留关键击杀/输出窗口/失能风险/未来成长等多项差分，再按支配关系和敏感性给首选；不临时给主C、前排和辅助的等级设固定系数充当战力。锦囊的ΔV与J沿用同一评价口径；已在路径结果体现的保护、击杀反馈或效果牌收益不重复加分。

概率或战力估值不全时，计算**翻转边界**，而不是“都可以”。例如在已声明的同一价值单位中，若觉醒比晚觉醒多保留A、升阶额外结果发生概率q且价值B、其余确定升阶收益T，则在确认不重叠后比较 `D=A−qB−T`：D>0选觉醒，D<0选升阶；B>0时分界为`q*=(A−T)/B`。A/B/T必须来自同一对照和单位；不能把9能量、12等级、10%抽卡率直接相减。若复杂结果不满足此简化，使用逐情景差分，不硬套一条阈值式。

- 有可信参数区间且同一动作全区间领先：输出这一动作，称稳健首选。
- 参数改变会翻转：把触发条件落实为该节点能观察/查询的进度、商店、概率、血量或关键组件情况；条件按优先顺序互斥，每片叶子只有一个动作。相等时先保留更多可逆资源，再以更少不可回收投入打破平局；这是预先声明的执行偏好，不是额外胜率证据。
- 参数未知且不能界定：说明哪项会翻转、给阈值与一个明确的临时执行动作。默认暂停该笔尚未被证明值得的不可逆投入，保留资源到下一次可观察节点；若有已证即时生存改进，先执行它。**这是信息不足时的执行规则，不能称为已证明最优；也不能顺势声称升阶必然最优。** 请求必要资料时继续完成与其无关的分析。

不能用“可以买觉醒，也可以存钱升本”“接近就补”“钱够就升”作为决策叶子；接近必须是具体剩余张数，领先必须有比较依据。每个叶子写唯一首选、放弃了哪个动作、下一回合检查点。只有在明确模型与参数内证明领先才能使用“最优”。

## 6. 必做反例检查与交付

检查：9点觉醒把关键门槛推迟；差1张和差3张结论不同；买了两张仍没完成觉醒；升阶但买不起高阶；锁牌与免费刷新改变曝光；升阶天赋决定战局；早到组件需要下一轮整备；低血无法等收益；继续投资会阻止更好的整体转型。对结论可能翻转的项给真实结果，不要求机械穷举无关组合。

报告仍先图和逐回合动作，再给关键节点的简短对照：首选动作、另一动作最早何时启动、净收益差或翻转阈值、最优结论适用范围。逐笔能量和抽槽账留在内部；用户明确问经济比较时才展开相关部分。未经此比较的旧觉醒/升阶时序标为未验证，不因预算已通过而继续复用。
