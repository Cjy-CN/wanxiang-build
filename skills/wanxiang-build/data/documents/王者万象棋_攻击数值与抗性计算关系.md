## 一、核心公式：抗性减伤

### 1.1 伤害倍率

```
有效抗性 = max(0, 抗性)
伤害倍率 = 40 ÷ (有效抗性 + 40)
减伤率   = 1 − 伤害倍率 = 有效抗性 ÷ (有效抗性 + 40)
实际伤害 = 未减伤伤害 × 伤害倍率
```

- **物理伤害**按目标**物防**计算倍率；**法术伤害**按目标**法防**计算；**真实伤害**无视抗性（倍率恒为 1）。
- 抗性最低为 0（负抗性按 0 处理，不增伤）。
- 该公式在引擎中以 `damage_multiplier=40/(resistance+40); damage_reduction=1-damage_multiplier` 形式编码，并附证据 ID `model:combat-math:resistance-multiplier-v0`。

## 二、伤害计算链（从攻击数值到最终伤害）

### 2.1 攻击间隔

```
攻击间隔(秒) = 1 ÷ 基础攻速
```

- 孙尚香 L10 攻速 1.05（416射手 10级节点）→ 攻击间隔 = 1/1.05 ≈ 0.9524 秒；DPS 事件第 1 次普攻时间戳恰为 0.9523809523809526，完全吻合。
- 攻速 1.0 → 每秒 1 次；攻速 0.6 → 每 1.667 秒 1 次。

### 2.2 普攻伤害

```
普攻伤害 = 物理攻击力 × 100%
```

- 验证（孙尚香 L10，物攻 56）：普攻 raw_value = 56 = 56 × 100%。

### 2.3 技能伤害

技能伤害按技能描述中的公式计算，格式为"固定值 + 系数 × 攻击/法强"：

```
技能伤害 = 固定值 + 系数 × 对应属性
```

- 验证（孙尚香·红莲爆弹，L10 物攻 56）：「造成 50+100%物理攻击力的物理伤害」→ raw = 50 + 1.0×56 = 106；参考结果 base_skill_damage_components 中 per_hit=106，公式 `per_hit=50.0+1.0*physical_attack` 完全一致。

### 2.4 最终伤害（套用抗性）

```
最终伤害 = 技能/普攻伤害 × 40 ÷ (对应抗性 + 40)
```

- 验证（孙尚香 L10 普攻 56 对木桩 40 物防）：56 × 40/(40+40) = 56 × 0.5 = **28**；参考结果 applied_value=28 ✓
- 验证（技能 106 对 40 物防）：106 × 0.5 = **53**

## 五、口径与假设
