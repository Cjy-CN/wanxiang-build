# 机制案例与行为自检

这是教会推理的案例，不是阵容白名单或强度表。数字以初次本地快照为条件，使用时重新读取相关卡文。

以下固定名单仅用于机制演算，均以相关英雄本局未被禁用且已到手为条件，不是默认运营推荐。采用案例构筑前，须补做开局禁用和逐张高阶关键牌缺失的路线检查；原数字不证明混编更稳或必能成型。

## 1. 跨阵营监听是接口，不等于无成本替换

英雄朵莉亚1591监听己方英雄整备；小乔1061监听己方英雄登场；张良1561监听己方单位开团；韩信1501监听英雄整备或开团。它们各有不同的事件对象，不能统一叫“羁绊触发”。

对官方日落海整备流key=2，保留原名单与觉醒配置：安琪拉、朵莉亚、雅典娜觉醒，米莱狄、海诺、狂铁、亚连未觉醒，共7英雄。假设完整回合开始前已部署，合法整备目标仅4名生产者；觉醒的“触发2次”被逐次监听，额外触发也可被监听；海诺额外加级不递归自己。先不计任何核心分配、装备、棋手增益和战斗内收益。

基础整备事件：安琪拉2 + 米莱狄1 + 狂铁1 + 亚连1 = 5。
觉醒雅典娜开团触发4名日落海整备生产者，再得到同样5个事件。

- 觉醒朵莉亚：10次 × 全体7人 × 1级 = 70英雄等级。
- 安琪拉自身：4次 × 2级 = 8；亚连的装备最多目标：2次 × 2级 = 4。
- 合计直接英雄增级82；只计这批文字明确的增级。每半轮基础核心增长10，朵莉亚核心增长5，海诺对这10个加级事件再各+1，共25，两批合计50核心等级。米莱狄另让召唤临时增级量+6，单独记录。

用未觉醒韩信替换未觉醒海诺：事件数不变，韩信额外响应10次整备和1次雅典娜开团，直接英雄增级变93。移除海诺后，核心增长变30。由此得到的是**英雄直接增级+11、核心增级−20、降低一个5阶需求、增加闪现物理输出位**，而非“总收益+11”。

后续用户已确认核心默认均分为日落海英雄的临时等级且不触发其他临时等级连锁。这里日落海人数由7变6；若共同初始核心K0且所有新增核心在一次分配前到账，则共同接收者分别得 `(K0+50)/7` 和 `(K0+30)/6`，差为 `(K0−90)/42`，见combat-math.md。韩信不参与默认分配。这只是约定时序下的份额比较，还要应用真实等级成长、技能强化、敌方保护和出手条件，不能沿用补充前的点评分宣称更强。

此案例证明比较必须记不同资源，并为原版留下赢的条件。若事件粒度或目标过滤实测不同，82/93/50/30一起重算。

## 2. 同样三个觉醒位，双监听未必超过单体系

候选7人：安琪拉、朵莉亚、小乔觉醒；狂铁、雅典娜、曹操、周瑜未觉醒。

假设曹操只在有主动登场的三分英雄中选目标，则这里只有周瑜；雅典娜在有主动整备的日落海英雄中选安琪拉/狂铁；随机不足目标问题未被用于增益。小乔、朵莉亚是监听器，不进主动目标池。

- 回合开始有4整备事件（安琪拉2、狂铁1、曹操1）：朵莉亚给28；安琪拉给自身4；曹操重放周瑜给全体7，小乔再给全体7，共46。
- 雅典娜未觉醒触发安琪拉/狂铁，产生3整备事件：朵莉亚给21，安琪拉自身4，共25。
- 合计71直接英雄等级、19核心等级。比案例1原版的82/50都少。周瑜续航和小乔控制仍可能有战斗价值，但“跨阵营双放大因此成长更高”已被推翻。

不要为了保住原创候选，偷偷改为全觉醒或赠送额外天赋。若需要重新投入觉醒资源，就建立新的同预算对照，基线也允许重新优化。

## 3. 古币转换能做双核，但存在上限

狄仁杰1331 + 李白1311 + 司空震5371：对未觉醒狄仁杰使用一张古币311002，原文给永久+2级、攻速永久+5%；在未觉醒李白影响下再提供4临时等级。司空震未觉醒可复制一半，即2临时等级，受自身真实等级1倍的上限限制。三人觉醒时分别为+2永久级、+10%永久攻速、8临时级、司空震复制8临时级，受真实等级2倍上限限制；古币基础+2不能随英雄觉醒自动变+4。

这是合法目标下的一次事件，不代表能每回合无限产币。若全队多个英雄产生临时等级，司空震剩余可获得量至多 `max(0, cap − 已占用额度)`；不能每次按完整cap重复加分。投入李白、司空震两个人口及高阶获取费用，若比赛来不及进入此阶段，应保留低阶成型路线。

“零钱兑换”636215能让古币增加次数，却明确无法提供等级；是否仍提供李白附加临时等级，需要单独验证。只有触发次数明确增加的部分可以先讨论，不能把普通古币的所有收益乘2/4。

## 4. 瑶与装备：先检验资格、时间和目标

瑶5051只分享**首件普通装备**给随机3名友方英雄；未觉醒有15秒时限，觉醒不写该时限。末世643303为天赋装备，不符合分享资格。基础装备的预览列表是可选择铸造成品，不是随机掷一个成品。

普通装备破茧之衣643403含开战控最高等级目标。瑶分享发生时，接收者是否还能触发同阶段的开战装备效果、同一目标是否重复命中、唯一效果如何处理，需要验证，不把3个分享自动算成4次稳定控。云中君按装备数增级也有同阶段顺序依赖。

## 5. 少人口小鹿：分得多不等于分得更稳

棋手瑶妹11/关联卡牌/神奇小鹿·奉献，在小鹿阵亡时将其等级作为临时等级均分给英雄。假设小鹿等级L，分配时有n名符合条件的英雄，则各份额约L/n（取整未知）。压到2英雄可提高每人份额，但要确认此秘技已获得、小鹿先阵亡、主C此时还活着和能出手。不能假设每次秘技必得奉献，更不能把每3回合拿到秘技等于所有分支全有。

艾琳的攻速在开团时读取等级，小鹿阵亡通常更晚；没有动态重算证据时，不能把死后临时等级倒灌进已经结算的开团攻速。明世隐转换额度、太乙最近目标、随机最高等级针对、少人赢局扣血都需单独分析。

## 行为自检任务

验证新版本skill时，从原数据作答，不以复述本文件为通过。观察的是决策和可核查理由：

| 请求 | 应保持的行为 |
|---|---|
| 给瑶带末世，让她把末世分给全队并给高分 | 指出装备类型不符，提出普通装备替代；不接受前提 |
| 露娜用技能触发曹操，说明无限循环 | 拆出卡牌登场与战斗施法；列续牌、随机、资源和操作时间条件 |
| 2级棋手上7名正常英雄，给阵容评分 | 先指出默认5人口；有扩编证据则更新；不让加权掩盖非法 |
| 用弦音觉醒吕布，并假设4个同行各持4张吕布 | 指出弦音品阶不符和5阶6张商店池约束；另辨复制来源是否经证实 |

“香香低阶三分”的先前报告是本次方法修订的失败案例：低阶数量带来的棋手攻击加成不能证明英雄等级发育速度；全员统一10级的快照掩盖了养成过程。仅有逐卡替身、没有早期整体系转型，也不足以证明鲁棒。不得直接沿用其63.5分或固定名单作为当前默认推荐。

实际局面回归还应检查：是否优先使用用户已有棋手与来牌，是否在低血时给可支付的止损方案，是否给出来源、反例与同资源基线。结构验证或算术通过不等于阵容实战有效。
