# 资料定位与规则边界

## 来源定位

默认资料根为本skill的 `data/`：`source_config.json` 中 `data_root` 的相对路径按SKILL.md所在目录解析，不按当前工作目录解析。用户显式指定外部资料根目录时才覆盖默认值。原项目的 `documents/` 与阵容 `references/` 已整体移动到 `data/documents/` 与 `data/references/`，保留原文和内部相对链接（分红截图已按用户要求删除，仅保留转录表格）；它们是维护中的原文，不是摘要缓存。整份skill可随项目移动，不依赖个人目录或旧项目绝对路径。文件缺失时报告具体缺项，继续使用不依赖它的部分。

下表中的 `documents/...`、`references/...` 均**相对data目录**；例如表中的 `references/官方推荐阵容_5套.json` 指 `data/references/官方推荐阵容_5套.json`。不要与本文件所在的分析方法目录混淆。项目根的 `analysis/` 保留历史研究报告，不是运行skill的必需输入。

初次研究快照为 2026-09-14 读取的用户资料，不代表线上最新平衡版本。可用 `lookup.py inventory` 获取路径、数量和 SHA-256，随报告保留指纹；文件变化后重新核对涉及的论断。

同日后续补充已加入分红比例转录、用户确认的核心均分规则及四份数值文档。原初步研究中的分数属于补充前的历史试评，已标记需要重评；不要继续将旧结论当作当前推荐。

2026-09-16用户确认了合成进度与效果锦囊规则：同名牌打到已上阵英雄计1次合成，每累计3次发放1张锦囊并清零；锦囊品阶按发放时棋手等级确定（6级按5阶）。打开锦囊消耗1张锦囊并生成3个独立抽取品阶的卡槽，按规则§3.1.1概率各生成1张对应品阶效果牌，玩家三选一；锦囊和效果牌不消耗能量，效果牌独立于公共英雄池且无张数概念。该规则会使“完成第三次合成”的时点同时影响等级成长、觉醒与效果牌机会成本。

用户后续实测补充的开局随机禁用一个阵营已写入规则§3.5.2；按确认规则使用，不再仅视为推荐帖传闻。逐张检查高阶关键牌的缺牌路线、实操先于分析的报告顺序属于用户的构筑与交付要求，不是游戏机制。

## 信任层级

1. 用户本次明确修订的规则 / 带版本的实际观察；注明其适用范围。
2. 本地具体卡牌原文及字段补充，以及用户补充的成长/技能/召唤物资料：是此次推导基础，但来源和完整性仍需核查。新增文件引用Wiki数据，“官方版本”标签和“权威公式”措辞不是额外的官方认证；抗性关系按其明确的木桩模型口径使用。
3. 本地通用规则说明中的明确机制条目。该文件末尾注明 AI 生成，不能把策略推论当规则。
4. 参考构筑的作者描述、标题、热度、推荐分。只能生成待检验假设。

具体觉醒文本优先于“觉醒全部翻倍”概述；同等层级冲突保留两个解释，不能挑更强的版本。若用户要求验证线上规则，另行查官方原始来源，记录版本差异；不需要为使用已提供内容额外抓取网页。

## 必须保留的缺口与易错点

- **已有数值资料但模型有边界。** 成长模板、技能强化、部分召唤物属性与抗性模型已补充，计算方法见combat-math.md。基础攻速以新表的0.6/0.8/1.0等每秒攻击次数读取，不将JSON中的6000直接代入。完整回蓝、攻速修正与上限、技能间隔、取整、缺失召唤字段等仍需核对；能估算单次伤害不等于能报精确胜率。孙尚香L10旧木桩样本与新成长/技能表不一致，分口径保留。
- **核心均分与连锁排除已确认。** 默认K/N临时级只给场上日落海英雄，不能全算给主C，也不能让司空震再复制。核心初始值、分配时点/频率、是否消耗、余数取整、临时级跨技能节点的语义仍未完整说明。定向传输有200级上限；能量改造/光棱塔“不再分配等级”，不得叠加默认分配收益。
- **基础合成增级未给出。** 不能偷用传统自走棋三星合成公式；曜的额外增级可单独算，总合成增级用未知参数。觉醒提升不总是乘2：小乔3名变全体，瑶15秒时限消失，甄姬随机变3选1，太乙变完美复生，海月伤害系数仅变1.5倍。
- **复生最多10次是上限，不是每人自带10次。** 完美复生恢复量及叠加/触发优先级未完整说明。复生后再次阵亡的监听逐条核对；小鹿阵亡不自动成为“英雄牺牲”。
- **传承7083 未明确**是否扣除目标等级、是否保留其场上存在、是否包含临时等级、分配时属性类型。不能把“裴擒虎临时等级反复传承”写成已证无限永久等级。遗志7041则明确移除目标、临时等级除外；移除不是出售/阵亡，不凭空触发退场/牺牲。
- **随机未承诺均匀。** 标注“随机N名不同”时可约束不重复，但不足N名如何处理、同一层级事件顺序仍可能未知。均匀抽样只能是假设，给最小/最大分支。
- **关键词列表不是主动触发器清单。** 小乔列出登场是解释其监听，朵莉亚列出整备也是监听；不能因此认为他们自己带主动登场/整备效果。以描述实际条件为准。
- **英雄卡池范围与生效时间已确认。** 英雄商店按≤生效阶数的合格英雄联合池计算；实体牌等权、同次四槽无放回须标明为计算假设。效果牌不在公共英雄池内，没有张数或占池扣除；效果锦囊打开后由3个独立品阶卡槽生成对应品阶效果牌并三选一。仍需按具体卡文核对效果牌功能限制、同槽重复和同回合使用次数。
- **装备容量/替换规则未完整给出。** 参考常见3件不等于完整槽位规则；不要默认任意拆装，已标“无法拆卸”严格遵守。瑶只分享首件普通装备，不能分享末世等天赋装备。基础装备铸造选项由玩家首次选择，选定后不可更改。
- **天赋“阶段”字段与升级选天赋的对应不明。** 保留该字段，但不能从“第八轮拍卖”推导第8回合可拿。未获天赋不当固定必备。开局禁阵营已由用户确认；其他仅出现在帖子中的赛季专属等说法不自动升格为通用规则。
- **分红比例已知，主动掉血仍非必赚。** 按规则§7.3查人数与排名；同档掉血不提高比例。池总额P已知时分红取整前为P×比例，未给池额则保留符号，不能免费补平预算。竞拍时间表、并列/取整、有效出价入池记账及后续生命价值仍需核对；嬴律高血成长、瑶妹胜利成长有反向激励。
- **存活英雄伤害与召唤物不同。** 牺牲阵容可能靠复生保留英雄，不能概括为必然淘汰效率低；小人口也可能让主C更强，但须评估赢后扣血、随机增益集中和失败风险的交换。
- **不要跨阶段制造因果。** 开战后加级不当然刷新已结算的艾琳开团攻速；开局狂飙允许施法不代表实际消耗法力值，自然法杖按消耗法力触发。变身、复制、无卡牌效果的召唤体不能默认继承生产引擎。

输出标注：`原文明确`、`按文本推导`、`待验证假设`、`实测观察（附样本）`。这些未知项不会永久冻结研究；新证据到来后更新分支。
