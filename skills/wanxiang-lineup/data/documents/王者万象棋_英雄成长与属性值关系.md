## 一、成长机制总览

- 英雄上阵初始 **1 级**，最高 **999 级**。
- 成长由两部分构成：
  1. **固定数值成长**：每升1级，生命、物攻、法攻按固定值线性增长，特殊等级也包含这部分成长（按文末计算公式）；
  2. **特殊升级奖励**：英雄升到 **10 级、40 级、100 级、150 级、200 级** 时获得一次性奖励，包含**属性节点加成**，其中 **10/40/100 级** 还会强化英雄技能。
- 全部 **85 名英雄**归入 **11 个成长模板**（类别）。**同一模板下所有英雄的数值成长完全相同**，差异仅体现在技能强化文本上。

## 附：成长计算公式

> 2026-09-14校对：开头“除特殊等级外”的表述已按本节公式和第四节“生命/物攻/法攻始终按固定成长”统一，避免漏算节点等级的固定成长。此处没有新增或改动任何成长数值。临时等级是否触发节点奖励/战斗技能强化仍需另有规则依据；不要因有此属性公式就自动认定所有升级事件均被触发。

任意等级属性可按如下公式计算：

```
属性(L) = 基础值 + 固定成长 × (L − 1) + Σ(已触发的特殊等级节点加成)
```

示例（物理坦克，200 级）：

```
生命 = 330 + 33 × 199 = 6897
物攻 = 32 + 1.6 × 199 = 350.4
物防 = 20 + (10级+2) + (40级+3) + (100级+3) + (150级+2) + (200级+2) = 32
```

示例（战士，200 级，含节点加成）：

```
物攻 = 40 + 2 × 199 + (10级+5 + 40级+5 + 100级+10 + 150级+5 + 200级+5) = 468
```
